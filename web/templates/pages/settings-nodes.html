Updates

Nodes update themselves from this server, one at a time, and roll back when the new version does not reach the server within five minutes. A node in a container is updated by pulling the image instead.{{if not $d.Release}} This server is a development build ({{$d.Version}}): nodes are never updated on their own, Update is offered only for nodes on {{$d.Own}}, and such a node takes the build only when it runs with -allow-unsigned-update.{{end}}
